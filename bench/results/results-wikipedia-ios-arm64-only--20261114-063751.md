# Benchmark: Wikipedia iOS (arm64 only), 3 parallel checkouts

MacBookPro18,4 · Apple M1 Max, 10 cores, 64 GB · macOS 27.2 · Xcode 27.2 Build version 27B52 · source 0919f3e

https://github.com/wikimedia/wikipedia-ios, the Wikipedia app: an .xcodeproj with Swift and Objective-C, local Swift packages (WMFData, WMFComponents, ...) and remote packages, built for the iOS Simulator; its git-ignored signing configuration is generated by the repository's own `scripts/setup_bundle_id ci`. Plain worktrees are set up as the project's README says and built with xcodebuild into the default DerivedData, as an agent would; xcfs is measured twice: slots driven by xcodebuild, and slots driven by the persistent build session. Swift packages are resolved by each side on its own (Xcode's global package cache is shared by both). This variant builds one architecture (ARCHS=arm64) on every side — what an agent needs for an Apple-silicon simulator — repeats the edit loop twice to show run-to-run noise, and also times `xcfs check` of the edited file.
